🌐 Cách Đưa Lên GitHub Chia Sẻ Bạn Bè

  1. Lưu mã nguồn trang web này thành một tệp duy nhất tên là index.html.
  2. Truy cập github.com, đăng nhập và tạo một kho lưu trữ mới (New Repository), đặt ở chế độ Public.
  3. Nhấn Add file → Upload files, tải tệp index.html lên và nhấn Commit changes.
  4. Vào mục Settings → Pages trong kho lưu trữ đó. Ở phần Branch, chọn main (thư mục /root) rồi bấm Save.
  5. Chờ khoảng 1 phút, GitHub sẽ cấp cho bạn một đường dẫn dạng https://ten-cua-ban.github.io/ten-repo/ để gửi cho bạn bè cùng mở trên điện thoại!
